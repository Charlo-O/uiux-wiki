## 3. 桌面/通用组件条目

共 62 个，来源于 `uiItems` 中 `category === "components"` 的条目。每个条目的内容字段会在详情面板、预览弹窗、列表搜索、信息网格和 mini preview 中复用。

### 1. 按钮 / Button

- ID：`button`
- 分类：组件 / 操作
- 摘要：触发一个操作或提交表单。
- 内容说明：按钮让用户执行一个明确动作，比如保存、继续、购买或删除。
- 别名：CTA、提交按钮、操作按钮
- 标签：表单、购买、后台、移动端
- 常见变体：主按钮、次按钮、描边按钮、文字按钮、图标按钮、危险按钮
- 状态：默认、悬停、按下、聚焦、禁用、加载中、成功
- 使用场景：登录、保存、提交、购买、删除、继续
- 建议：一个区域只突出一个主要按钮、危险操作要明确提示、按钮文字写清动作
- 避免：不要把所有按钮都做成主按钮、不要只放图标却没有说明、不要让禁用按钮没有原因
- 无障碍提醒：可用键盘访问、焦点状态清楚、不要只靠颜色表达状态
- 相关条目：链接(link)、图标按钮(icon-button)、菜单(menu)、弹窗(modal)
- 预览类型：`button`
- 对比说明：按钮 vs 链接：按钮负责执行动作，链接负责跳到位置或资源。

### 2. 输入框 / Text Field

- ID：`text-field`
- 分类：组件 / 输入
- 摘要：让用户输入或编辑信息。
- 内容说明：输入框通常出现在登录、搜索、表单填写和设置页面里。
- 别名：文本框、输入栏
- 标签：表单、登录、设置
- 常见变体：单行输入、带图标输入、带清除按钮、错误输入、只读输入
- 状态：默认、聚焦、已填写、错误、禁用
- 使用场景：填写姓名、输入邮箱、搜索关键词、输入验证码
- 建议：名称写清楚、状态要能被看懂、和周围内容保持一致
- 避免：不要让它看起来可点却不能点、不要把同一层级做得都很抢眼、不要省略错误或禁用原因
- 无障碍提醒：可用键盘访问、焦点状态清楚、不要只靠颜色表达状态
- 相关条目：多行输入框(textarea)、搜索框(search)、密码框(password-field)、选择器(select)
- 预览类型：`text`
- 对比说明：输入框 vs 选择器：输入框适合自由填写，选择器适合从固定选项中选。

### 3. 弹窗 / Modal

- ID：`modal`
- 分类：组件 / 反馈
- 摘要：盖在页面上的重要提示或任务。
- 内容说明：弹窗会打断当前流程，通常用于确认删除、支付、退出登录等关键操作。
- 别名：Dialog、对话框、确认框
- 标签：确认、危险操作、表单
- 常见变体：确认弹窗、表单弹窗、全屏弹窗、底部弹窗
- 状态：打开、关闭、加载、错误、成功
- 使用场景：删除确认、支付确认、编辑资料、登录提示
- 建议：名称写清楚、状态要能被看懂、和周围内容保持一致
- 避免：不要用弹窗展示普通提示、不要一进入页面就弹出多个弹窗、不要隐藏关闭入口
- 无障碍提醒：可用键盘访问、焦点状态清楚、不要只靠颜色表达状态
- 相关条目：Toast(toast)、警告(alert)、抽屉(drawer)、浮层(popover)
- 预览类型：`modal`
- 对比说明：弹窗 vs Toast：弹窗需要处理，Toast 只是短暂告诉用户结果。

### 4. Toast / Toast

- ID：`toast`
- 分类：组件 / 反馈
- 摘要：短暂出现的轻量提示。
- 内容说明：Toast 通常出现在页面角落，告诉用户刚刚的操作结果，比如保存成功。
- 别名：轻提示、Snackbar
- 标签：成功、错误、保存
- 常见变体：成功提示、错误提示、可撤销提示、带操作提示
- 状态：进入、显示、自动消失
- 使用场景：保存成功、复制成功、网络失败、删除后撤销
- 建议：名称写清楚、状态要能被看懂、和周围内容保持一致
- 避免：不要让它看起来可点却不能点、不要把同一层级做得都很抢眼、不要省略错误或禁用原因
- 无障碍提醒：可用键盘访问、焦点状态清楚、不要只靠颜色表达状态
- 相关条目：警告(alert)、弹窗(modal)、通知(notification)
- 预览类型：`toast`
- 对比说明：Toast vs Alert：Toast 短暂，Alert 更显眼也更持久。

### 6. 标签页 / Tabs

- ID：`tabs`
- 分类：组件 / 导航
- 摘要：在同一区域切换不同内容。
- 内容说明：标签页用于同一页面内的内容切换，比如详情、评论、参数。
- 别名：Tab、页签
- 标签：导航、详情页、设置
- 常见变体：下划线标签、胶囊标签、垂直标签、可滚动标签
- 状态：默认、选中、悬停、禁用
- 使用场景：商品详情、设置分组、数据视图、文档切换

- 预览类型：`tabs`
- 对比说明：标签页 vs 分段控制：标签页切换大内容，分段控制常切换视图模式。

- 新增桌面/通用组件：优先在 `src/data.js` 添加 `category: "components"` 条目，并补齐 `title`、`english`、`group`、`summary`、`plain`、`variants`、`states`、`useCases`、`related`、`preview`。
- 新增页面布局：在 `src/data.js` 添加 `category: "layouts"` 条目，同时在 `LayoutLivePreview` 的映射表和 `LayoutScene` 中确认是否已有合适模板。
- 新增移动端组件：在 `src/App.jsx` 的 `mobileComponents` 添加条目，必要时扩展 `MobilePreview` 的 `preview` 分支。
- 新增 preview 类型：同步检查 `MiniPreview`、`ComponentLivePreview` 或 `LayoutPreview` 等预览路由，避免列表卡和详情预览不一致。
- 修改条目命名：同步检查 `related` ID、`comparisonPairs`、首页核心入口、搜索标签和截图验证用例。
